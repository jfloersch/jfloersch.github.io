Product

What is AgentPace?

AgentPace is a macOS menu bar app that graphs coding-agent usage and compares it against an ideal pace so you can see whether you are likely to run out before your usage window resets.

Who is AgentPace for?

AgentPace is for developers who use Claude Code, Codex, or similar coding agents often enough that usage limits affect planning. It is especially useful if you want a quick menu bar answer instead of a dashboard.

What coding agents does AgentPace support?

AgentPace is designed around Claude Code and Codex-style usage windows, including weekly and shorter reset windows.

How is AgentPace different from other usage trackers?

A counter tells you how much you have used. AgentPace shows whether that usage is ahead of or behind pace and helps forecast whether you are likely to hit your limit early.

Does AgentPace show forecasts?

AgentPace focuses on usage pace. By comparing actual usage with an ideal line, it helps you see whether the current burn rate is likely to create a problem before reset.

Privacy

Does AgentPace upload usage data?

No. AgentPace is a local macOS utility with no account, cloud dashboard, telemetry, ads, or analytics.

Does AgentPace require an account?

No. AgentPace does not require an AgentPace account to use the app.

Does AgentPace include analytics?

No. AgentPace does not include third-party analytics, advertising, tracking, or crash-reporting integrations.

Does AgentPace run locally?

Yes. AgentPace runs as a native macOS menu bar app. Usage snapshots and refresh errors are stored locally on your Mac.

Purchase

How does the 7-day trial work?

AgentPace has a 7-day free trial. After that, it can be unlocked with a $4.99 lifetime license key.

What does the $4.99 lifetime unlock include?

The lifetime unlock keeps AgentPace available after the trial on the licensed Mac and covers the app as a small direct-purchase utility.

How do license keys work?

After purchase, the license key unlocks AgentPace after the trial. Keep the key somewhere safe in case you need to reinstall.

Can I move my license to a new Mac?

If you need help with a new Mac or license issue, email support and include the purchase details you have available.

Installation

Why is AgentPace distributed outside the Mac App Store?

AgentPace is distributed directly because it needs to work as a focused local developer utility outside the normal App Store flow.

Is AgentPace signed and notarized?

Check the current release notes or download page for the exact signing and notarization status of the latest build. The product page links to the current DMG release.

How do I install AgentPace?

Download the DMG from the AgentPace product page, open it, and install the app like a normal macOS utility.

How do I update AgentPace?

Download the latest DMG from the current GitHub release and replace the older app build.

How do I uninstall AgentPace?

Quit AgentPace and remove the app from your Mac. You can also clear local history from the app settings before uninstalling.

Roadmap

Will AgentPace support more coding agents?

AgentPace should be designed to support more coding-agent usage windows over time, especially if users ask for them.

Will AgentPace support custom limits?

Custom limits are a natural fit for a pace meter, but they should be added only when the app can keep the setup simple.

Will AgentPace support alerts?

Alerts could be useful if they stay quiet and actionable. The app should remain a focused menu bar utility, not a noisy monitoring product.
