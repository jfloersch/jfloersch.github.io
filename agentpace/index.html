How it works

A budget line for your agent usage.

Percent-used numbers are hard to reason about in the middle of a work session. AgentPace turns the same quota windows into a pace question: are you ahead, behind, or right where you expected to be?

Watch weekly and 5-hour windows

AgentPace keeps the two quota windows developers care about in one compact menu-bar popover, with separate charts and plain-language pace summaries.

Compare actual usage to the ideal line

Each chart overlays your actual remaining usage against a simple linear budget line, so you can see when you are burning faster than planned.

Switch between Codex and Claude Code

Use the provider picker to check either tool. Manual refresh, refresh-on-open, and optional polling keep the app small without turning it into another dashboard.

Why AgentPace

Built for checking pace, not analyzing everything.

No provider marketplace, cost analytics, browser scraping, WebView login, widgets, notifications, or cloud account. AgentPace is intentionally small.

Menu-bar only

A static icon opens a compact native popover. No Dock icon, no dashboard to manage, no extra workflow.

Local provider access

Codex usage is read through the local Codex CLI app-server. Claude can use AgentPace's own Keychain token or local Claude Code credentials.

Plain decisions

Under pace means you have room. Over pace means slow down, switch providers, or save capacity for later.

Privacy by construction

Your agent usage stays on your Mac.

AgentPace has no analytics, telemetry, ads, backend, or account system. It reads local login state only to fetch usage directly from the provider endpoints, then stores short-term history locally.

  • Tokens are not uploaded, synced, or stored in AgentPace settings or history.
  • AgentPace-owned Claude credentials are stored in the macOS Keychain.
  • Usage snapshots and refresh errors are stored locally for 30 days.
  • Clear local history from Settings whenever you want.
